# Product

## Register

product

## Platform

web

## Users

Cordon serves developers, freelancers, job applicants, auditors, and maintainers who receive unfamiliar public repositories and need to decide whether the code is safe enough to inspect or execute locally. The primary user is technically fluent but working under uncertainty and wants evidence, not a conversational assurance.

## Product Purpose

Cordon downloads a public GitHub repository into temporary isolated storage, performs deterministic static analysis without executing repository code, and presents an evidence-backed risk report. Success means the user can trace each concern to a file and line, understand any combined attack path, and make an informed review decision before the repository reaches their machine.

## Positioning

Inspect unknown code before it reaches your machine.

## Brand Personality

Technical, austere, and precise. Cordon speaks like a careful security reviewer: direct about evidence, explicit about uncertainty, and never theatrical.

## Anti-references

Cordon must not resemble a generic AI chatbot or neon cyber-security demo. Avoid glassmorphism, excessive gradients, giant marketing headlines, floating decorative cards, fake terminal animations, generic sparkle icons, fictional findings, and claims that a low-risk result guarantees safety.

## Design Principles

1. Put the repository action and current scan state ahead of marketing copy.
2. Make every risk claim traceable to evidence, files, and lines.
3. Separate deterministic findings from combined attack-path reasoning.
4. Use restrained product controls and dense, readable information design.
5. Never fabricate repository activity, scan results, or safety guarantees.

## Accessibility & Inclusion

No formal conformance level has been certified. The implementation targets readable contrast, semantic landmarks, visible labels and focus states, keyboard-operable controls, non-colour severity labels, touch-sized targets, reduced-motion behavior, and responsive layouts at 320, 375, 414, 768, and 1440 pixel widths. A formal WCAG audit remains required before public launch.
